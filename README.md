# Диффузия лёгкого газа в тяжёлом — метод пробных частиц

**Нураев Тимур, Б05-506**

## О проекте

Моделирование диффузии разреженного лёгкого газа в тяжёлом фоновом газе методом пробных частиц. Молекулы фонового газа не моделируются явно — на каждом шаге вычисляется вероятность столкновения пробной частицы с фоновой средой и разыгрывается исход столкновения. Результаты сравниваются с аналитическим решением уравнения диффузии и законом Эйнштейна ⟨r²⟩ = 6Dt.

## Структура проекта

```
.

```

## Метод

Вместо явного моделирования N молекул фонового газа на каждой итерации:

1. Вычисляется вероятность столкновения за шаг времени Δt: P = 1 − exp(−Δt/τ), где τ = λ/⟨v⟩ — среднее время между столкновениями.
2. Если столкновение произошло, разыгрывается новая скорость пробной частицы из распределения Максвелла для фонового газа.
3. Позиция обновляется: **r**(t + Δt) = **r**(t) + **v** · Δt.

Такой подход (метод пробных частиц, test-particle Monte Carlo) корректен в пределе малой концентрации лёгкого газа.

## Запуск

```bash
c++ main.cpp           # запуск симуляции, запись в results.csv
python analytic.py     # анализ и построение графиков
```

Параметры симуляции задаются в `config.json`.

## Что проверяется

- Профиль концентрации c(r, t) сравнивается с гауссовым решением уравнения диффузии.
- Зависимость ⟨r²⟩(t) проверяется на линейность; наклон даёт экспериментальное D.
- Полученное D сравнивается с теоретической оценкой из кинетической теории: D ~ ⟨v⟩λ/3.
